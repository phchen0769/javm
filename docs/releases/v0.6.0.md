# JAVM v0.6.0

> `v0.5.3` → `v0.6.0`

## 新增

- 匹配成功后自动下载简体中文字幕，保存在视频旁（`视频名.zh.srt`），可被 Jellyfin、Emby 等直接识别；可在「设置 → 元数据存储」中开关。
- 视频详情页新增「下载字幕」，可随时手动为单个视频补下字幕。
- 视频列表新增「字幕」标识，一眼看出哪些视频已有字幕。
- 设置里的刮削数据源、下载源现在直接显示各站点网址，便于辨认。
- 设置界面支持自定义视频扩展名（如 `.strm`），扫描时与内置格式一同识别。

## 优化

- 更换了全新应用图标，macOS 窗口加入原生红绿灯按钮，整体观感更协调。

## 修复

- 修正 123av 下载源的失效路径，恢复该源的链接获取。
