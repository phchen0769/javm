# JAVM v2.0.0

> `v0.6.0` → `v2.0.0`

## 新增

- 新增「网站收藏」功能：在侧栏即可收藏、整理常逛的站点。
- 媒体库支持翻页浏览，可自由切换分页与无限滚动，上千条影片也能顺畅翻阅。
- 刮削新增多个数据源，更多影片能找到元数据。

## 优化

- 媒体库滚动更流畅，封面改为缩略图加载，大库浏览不再卡顿。
- 刮削产物更好地兼容 Jellyfin：封面格式受限时不落盘、多段影片按通行规则命名，媒体库能正确识别与堆叠。

## 修复

- 删除视频改为移入系统回收站，误删可从回收站恢复，不再直接永久删除。
- 详情页修改标题保存后，不再误改磁盘上的文件名与番号。
- 恢复卡片模式下的右键菜单。
- 封面写入失败不再把原封面截成 0 字节。
- 修复部分场景下列表数据不刷新的问题。
